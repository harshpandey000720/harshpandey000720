### 🔹 SiliconWatch

**Hardware Telemetry & Predictive Fault Watchdog**

A systems-oriented project connecting my **Instrumentation Engineering background with software and systems engineering**, focused on collecting, processing and visualizing low-level hardware telemetry.

**Engineering focus:**

* 🔌 Native hardware interaction using **Java Native Access (JNA)**
* ⚡ Low-overhead hardware telemetry collection
* 📈 High-throughput time-series telemetry pipeline
* 🔄 Real-time telemetry streaming using WebSockets
* 🗄️ TimescaleDB / PostgreSQL persistence
* 📊 GPU clock-frequency & voltage anomaly detection
* 🌡️ Thermal-gradient analysis
* 🖥️ OS-level process correlation using OSHI
* 📡 Real-time React observability dashboard

**Stack:**
`Java` `JNA` `OSHI` `Spring Boot` `Netty` `WebSockets` `PostgreSQL` `TimescaleDB` `React`
